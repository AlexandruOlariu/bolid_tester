# Sniffer captures

Bus captures from the **Bus sniffer** (More → Bus sniffer, [can-sniffer](../features/can-sniffer.md))
that serve as **evidence** for a `confirmed` profile item
([vehicles → `confirmed`](../vehicles/README.md#confirmed--evidence-that-an-item-was-checked-on-the-car)).
Plan 25 built the tooling; the captures themselves come from the owner's on-car sessions.

## What to commit

- **CSV only** (`Share CSV` in the sniffer), never the raw dump — the CSV keeps every parsed frame
  plus the unparsed lines in its trailing `# raw:` block.
- **Trimmed to the relevant window**: the header comment lines, the `t_ms,id,dlc,bytes` row and the
  frames around the action (a few seconds before and after). Keep the `# note:` line — it says what
  was done ("VCDS Group 121 basic settings ON then OFF, engine idle").
- No VIN, no login codes: VCDS `2B` login requests carry the module's login code — cut those rows
  (the analyzer's report, Markdown or `--json`, cuts a `2B` request to its service byte, but the
  CSV itself would still carry the code).

## Naming

`<vehicle>-<flow>-<date>.csv`, e.g. `golf-plus-2009-20tdi-group121-2026-11-20.csv`. `<vehicle>` is
the registry id, `<flow>` a short slug of what was recorded, `<date>` the capture day (`YYYY-MM-DD`).

`synthetic-golf.csv` is **not** a real capture: it is generated by
`src/shared/obd-core/analysis/captureAnalyzer.test.ts` (rewrite it with
`UPDATE_FIXTURES=1 npx jest captureAnalyzer`) and exists so CI exercises the analyzer CLI.

## Running the analyzer

```bash
npm run analyze:capture -- docs/captures/<file>.csv                       # Markdown report
node scripts/analyze-capture.mjs <file>.csv --around 41200 --window 3000  # ±3 s around t=41.2 s
node scripts/analyze-capture.mjs <file>.csv --id 7E0                      # only 7E0 ↔ its replies
node scripts/analyze-capture.mjs <file>.csv --json                        # machine-readable
```

The CLI runs the TypeScript analyzer (`src/shared/obd-core/analysis/captureAnalyzer.ts`) directly
through Node's type stripping (Node ≥ 22.18). The report has:

- **Fingerprints** — requests grouped by service + sub-function + DID / routine id (`31 01 0301`,
  `2F 0130`, `22 F187`) with count and first / last time: the fastest way to see "what did VCDS send
  when I pressed ON in Group 121".
- **Requests and responses** — every request paired with its answer (positive, or `7F` with the
  ISO 14229 name of the code, e.g. `securityAccessDenied`), "response pending" (`7F xx 78`) skipped,
  with the latency. Multi-frame messages are reassembled from raw ISO-TP frames (first / consecutive
  / flow-control). The sniffer records with headers on (`ATH1`), so every frame carries its PCI byte.
- **TP2.0** — channel setups on `0x200` and their answers on `0x200 + address`, the negotiated data
  channels and their `A3` keep-alive counts. TP2.0 frames are never parsed as ISO-TP. A capture
  trimmed past the channel setup still works: an id in `0x300`–`0x3FF` is a channel, and so is a
  `0x600`–`0x7FF` id (e.g. the tester's `0x740`) that sends a TP2.0-only opcode — `A0` / `A1` /
  `A3` / `A4` / `A8`, or a `9x` / `Bx` ACK, which ISO-TP never sends.
- **CAN ids** — frames per id with first / last time.

Only diagnostic ids (11-bit `0x600`–`0x7FF`, 29-bit `18DA…` / `18DB…`) are reassembled by default;
`--all-ids` includes the rest of the bus.

## Turning a finding into `confirmed`

1. Commit the trimmed CSV here.
2. Make the one-line profile change the finding supports (a routine `id`, a DID, a module's
   `reqHeader` / `rxFilter`, a preset bit), and add
   `confirmed: { on: '<date>', source: 'sniffer-capture', fixture: 'docs/captures/<file>.csv', note: '<fingerprint>' }`.
3. Add a row to the vehicle doc's "Validated on the car" table when a plan-02 fixture is involved.
4. `npm test` — the docs-sync test fails if the `fixture` path does not exist; the screen badge
   turns blue.

What to look for per flow (Group 121, DPF regeneration, extended DIDs, service reset, tweaks) is in
[plan 25 → Deferred until an on-car session](../plans/25-post-capture-confirmation.md#deferred-until-an-on-car-session).
